# Frontend Dashboard

## Overview

The frontend dashboard provides a visual interface for reviewing security events and alerts generated by the SIEM.

The dashboard is built with React and retrieves live event and alert data from the FastAPI backend.

---

## Dashboard Metrics

The dashboard displays:

- Total Events
- Active Alerts
- High Severity Alerts
- Medium Severity Alerts

These values are calculated from the event and alert data returned by the backend.

---

## Alert Severity Visualization

Chart.js is used to display the distribution of alert severity.

The chart shows:

- High severity alerts
- Medium severity alerts

This gives the analyst a quick visual overview of the current alert distribution.

---

## Alert Filtering

The Recent Alerts table supports filtering by:

- All Alerts
- High Severity
- Medium Severity
- Account Lockout
- Repeated Failed Logins

This allows an analyst to quickly focus on specific alert types or severity levels.

---

## Event Filtering

The Recent Events table supports filtering by:

- All Events
- Failed Login
- Successful Login
- Account Lockout

This allows an analyst to narrow the event view to specific authentication activity.

---

## Analyst Workflow

An analyst can use the dashboard to:

- Review overall event volume
- Review active alerts
- Identify high-severity activity
- Review recent alerts
- Review recent events
- Filter alerts by severity or type
- Filter events by event type
- Review the alert severity distribution
